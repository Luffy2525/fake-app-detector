How ShieldScan Works

01
📦

APK Preprocessing

Extracts APK structure, validates ZIP format, computes MD5/SHA256 hashes, reads AndroidManifest.xml, and checks for native code libraries.

→
02
🔐

Permission Analysis

Maps all 30+ permissions against a curated risk database. Categorizes into HIGH/MEDIUM/LOW risk and computes a permission risk score (0–100).

→
03
🎭

Dark Pattern Detection

Scans app name, description, and metadata for 10 dark pattern categories: hidden costs, trick questions, confirm-shaming, urgency traps, and more.

→
04
🕵️

Fake App Detection

Checks file hash against malware databases, identifies cloned app names, suspicious developers, malicious APK distribution domains, and overlay attack patterns.

About

Built for Real-World Security

ShieldScan is a mini-project demonstrating a full-stack Android app security analysis system. It combines static APK analysis, NLP-based dark pattern detection, and signature-based fake app identification.

Built with Python Flask backend and a pure HTML/CSS/JS frontend — deployable on any cloud platform including Render, Railway, Heroku, or your own server.
